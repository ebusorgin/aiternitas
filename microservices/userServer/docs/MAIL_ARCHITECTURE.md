## 1. Mail Infrastructure (сервер)

Почта для домена **@aiternitas.ru** принимается и отправляется вашим сервером.

### 1.1 Postfix (SMTP)

- **Приём входящих**: порт 25 (MX), письма для `*@aiternitas.ru` передаются в приложение по LMTP/SMTP на порт **2525** (текущий `MAIL_PORT`).
- **Submission**: порт 587 (TLS) — приложение отправляет письма через `localhost:25` или `localhost:587`.
- **Виртуальные ящики**: доставка по адресу `localpart@aiternitas.ru` → приложение определяет пользователя по `mail_login` и сохраняет в БД.

### 1.2 Dovecot (IMAP) — опционально

- Порт 993 (IMAPS) для доступа из внешних клиентов (Thunderbird, Outlook).
- В первой версии веб-интерфейс читает/пишет только через API и БД; Dovecot можно добавить позже для синхронизации с maildir.

### 1.3 Rspamd (антиспам)

- Интеграция с Postfix через milter.
- Снижает объём спама во входящих.

### 1.4 DKIM / SPF / DMARC

- **DKIM**: подпись исходящих писем ключом домена (opendkim или postfix-dkim).
- **SPF**: запись в DNS `v=spf1 mx ~all` или `include:_spf.aiternitas.ru`.
- **DMARC**: запись `_dmarc.aiternitas.ru` для политики проверки.

### 1.5 TLS (Let's Encrypt)

- Сертификаты для SMTP (587) и IMAP (993) через certbot.

## 2. Backend API (Node.js)

- **Единая авторизация**: сессия сайта = доступ к почте.
- **Пользователь = почтовый ящик**: при первом заходе в «Почта» пользователь задаёт **логин** (например `severomorets`) → адрес `severomorets@aiternitas.ru`.
- **API**:
  - `GET /api/mail/me` — информация о ящике (mail_login, адрес, есть ли ящик).
  - `POST /api/mail/setup` — создать ящик (задать mail_login один раз).
  - `GET /api/mail/folders` — папки и счётчики (входящие, отправленные, черновики, спам, корзина).
  - `GET /api/mail/messages?folder=&page=&limit=` — список писем в папке.
  - `GET /api/mail/messages/:id` — одно письмо (тело, вложения).
  - `PUT /api/mail/messages/:id` — отметить прочитанным, переместить в папку.
  - `POST /api/mail/send` — отправить письмо (To, CC, BCC, тема, тело, вложения).
  - `POST /api/mail/drafts` — сохранить черновик.
  - `DELETE /api/mail/messages/:id` — удалить (в корзину или окончательно).

- **Отправка**: через localhost (Postfix); внешний SMTP не используется.
- **Защита**: rate limit, requireAuth.

## 3. Frontend (внутри сайта)

- **Меню**: один пункт «Почта» → `/mail`.
- **Если ящик не создан**: экран «Придумайте логин» → после сохранения — полный интерфейс.
- **Интерфейс (как Gmail)**:
  - Левая колонка: Входящие, Отправленные, Черновики, Спам, Корзина.
  - Основная область: список писем (отправитель, тема, превью, дата, непрочитано).
  - Просмотр письма: заголовки, тело (HTML/text), вложения.
  - Написать: Кому / Копия / Скрытая копия, тема, тело (rich text), вложения, «Отправить».
