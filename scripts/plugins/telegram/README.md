# Генерация Session String для Telegram аккаунта

Для подключения Telegram в режиме "аккаунт" (MTProto) требуется **авторизованная сессия** (Session String).

## Что вам понадобится

1. **API ID** и **API Hash** с https://my.telegram.org → API development tools
2. **Номер телефона** вашего Telegram аккаунта (формат: +79991234567)
3. **Доступ к Telegram** для получения кода подтверждения
4. **Пароль 2FA** (если включена двухфакторная аутентификация)

## Шаги

### 1. Откройте my.telegram.org

- Зайдите на https://my.telegram.org
- Войдите через свой номер телефона + код из Telegram
- Перейдите в **API development tools**
- Создайте приложение (если ещё нет):
  - **App title**: aiternitas (любое имя)
  - **Short name**: aiternitas (5-32 символа)
- Скопируйте **App api_id** и **App api_hash**

### 2. Сгенерируйте Session String

```bash
cd /home/sever/WebstormProjects/aiternitas
node scripts/plugins/telegram/generate-session.mjs
```

**Скрипт спросит:**
1. API ID (число) → вставьте App api_id
2. API Hash → вставьте App api_hash
3. Номер телефона (+7999...) → ваш номер
4. Код из Telegram → откройте Telegram и введите код
5. Пароль 2FA (если есть) → введите, иначе нажмите Enter

**Результат:**
```
=== Session String ===

1AgAOMTQ5LjE1NC4xNjcuNTEBuwHvW...очень длинная строка...

Скопируйте и вставьте в плагин: "Серверная сессия (Session String)".
```

### 3. Вставьте Session String в плагин

1. Откройте Aiternitas → плагин Telegram
2. Выберите режим "Telegram аккаунт (серверно, MTProto)"
3. Заполните:
   - **API ID**: 35115172
   - **API Hash**: 3a86bee7a54b8b364f4532c2dc6f91af
   - **Session String**: вставьте сгенерированную строку
4. Нажмите **"Протестировать соединение"**

✅ При успехе в ваш Telegram придёт сообщение в "Избранное" (Saved Messages)

## Важно

- **Session String** - это авторизованная сессия, которая **не требует пароля** при каждом использовании
- **Храните Session String в секрете** - с ней можно управлять вашим аккаунтом
- **API ID/Hash без Session String не работают** - они только ключи приложения
- Если Session String утечёт, завершите все сессии в Telegram → Настройки → Конфиденциальность → Активные сессии

## Режим "Telegram бот" (проще)

Если вам не нужны возможности аккаунта, используйте режим **"Telegram бот"**:

1. Откройте @BotFather в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте токен бота (123456:ABC...)
4. Добавьте бота в чат/канал
5. Узнайте ID чата (например, через @userinfobot)
6. Заполните в плагине:
   - **Токен бота**: 123456:ABC...
   - **ID чата/канала**: -1001234567890

Готово! Бот может отправлять сообщения в указанный чат.
