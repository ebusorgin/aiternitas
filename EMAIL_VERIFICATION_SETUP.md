# Настройка верификации email

## Описание

Система верификации email автоматически проверяет email адреса пользователей, зарегистрировавшихся через обычную регистрацию (не через Google OAuth).

## Как это работает

1. **При регистрации:**
   - Пользователь регистрируется с email и паролем
   - Генерируется уникальный токен верификации
   - На email пользователя отправляется письмо со ссылкой для подтверждения
   - Пользователь может войти, но будет видеть предупреждение о неподтвержденном email

2. **При входе:**
   - Если email не подтвержден, вход блокируется с сообщением
   - Пользователь может запросить новое письмо для подтверждения

3. **Подтверждение email:**
   - Пользователь переходит по ссылке из письма
   - Email подтверждается автоматически
   - Пользователь автоматически входит в систему

4. **Google OAuth:**
   - Пользователи, зарегистрированные через Google, автоматически имеют подтвержденный email
   - Для них верификация не требуется

## Настройка SMTP

Для отправки реальных писем необходимо настроить SMTP сервер. Добавьте следующие переменные окружения в `.env`:

```env
# SMTP настройки
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
SMTP_FROM=noreply@aiternitas.ru

# URL фронтенда (для ссылок в письмах)
FRONTEND_URL=https://aiternitas.ru
```

### Примеры SMTP провайдеров

#### Gmail
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password  # Используйте пароль приложения, не обычный пароль
```

**Как получить пароль приложения Gmail:**
1. Перейдите в [Настройки аккаунта Google](https://myaccount.google.com/)
2. Включите двухфакторную аутентификацию
3. Перейдите в [Пароли приложений](https://myaccount.google.com/apppasswords)
4. Создайте новый пароль приложения для "Почта"
5. Используйте этот пароль в `SMTP_PASS`

#### Mail.ru
```env
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=your-email@mail.ru
SMTP_PASS=your-password
```

#### Yandex
```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=your-email@yandex.ru
SMTP_PASS=your-password
```

#### SendGrid
```env
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USER=apikey
SMTP_PASS=your-sendgrid-api-key
```

#### Mailgun
```env
SMTP_HOST=smtp.mailgun.org
SMTP_PORT=587
SMTP_USER=your-mailgun-username
SMTP_PASS=your-mailgun-password
```

## Без SMTP (для разработки)

Если SMTP не настроен, система будет:
- Логировать ссылки для верификации в консоль сервера
- Позволять тестировать функционал вручную
- Показывать ссылки в ответах API (только для отладки)

**Внимание:** В продакшене обязательно настройте SMTP для реальной отправки писем!

## Проверка работы

1. Зарегистрируйте нового пользователя через обычную регистрацию
2. Проверьте почту на наличие письма с подтверждением
3. Перейдите по ссылке из письма
4. Убедитесь, что email подтвержден и вы автоматически вошли

## Диагностика проблем

### Письма не приходят

1. **Проверьте логи сервера:**
   ```bash
   journalctl -u aiternitas-main.service -f
   ```
   
   При попытке отправки письма вы должны увидеть:
   - `📧 Проверка настроек SMTP:` - показывает, какие настройки установлены
   - `✅ Подключение к SMTP серверу успешно` - если SMTP настроен правильно
   - `✅ Email успешно отправлен` - если письмо отправлено
   - `❌ Ошибка отправки email:` - если есть ошибка (с деталями)

2. **Проверьте настройки SMTP:**
   - Убедитесь, что все переменные окружения установлены
   - Для Gmail используйте пароль приложения, не обычный пароль
   - Проверьте, что порт правильный (587 для TLS, 465 для SSL)

3. **Тестовая отправка:**
   После авторизации можно отправить тестовое письмо:
   ```bash
   curl -X POST https://aiternitas.ru/api/auth/test-email \
     -H "Content-Type: application/json" \
     -d '{"email":"your-email@example.com"}' \
     --cookie "connect.sid=your-session-cookie"
   ```

4. **Проверьте спам:**
   - Письма могут попадать в папку "Спам"
   - Проверьте все папки почтового ящика

5. **Если SMTP не настроен:**
   - В логах будет сообщение: `⚠️  SMTP не настроен`
   - Ссылка для подтверждения будет в логах сервера
   - Настройте SMTP для реальной отправки писем

## API Endpoints

- `POST /api/auth/register` - Регистрация (автоматически отправляет письмо)
- `POST /api/auth/login` - Вход (проверяет верификацию email)
- `GET /api/auth/verify-email?token=...` - Подтверждение email
- `POST /api/auth/resend-verification` - Повторная отправка письма (требует авторизации)

## База данных

Система использует следующие поля в таблице `users`:
- `email_verified` (BOOLEAN) - статус подтверждения
- `email_verification_token` (VARCHAR) - токен для подтверждения
- `email_verification_expires` (TIMESTAMP) - срок действия токена (24 часа)

Эти поля автоматически создаются при первом запуске приложения.
