# Почему используется 127.127.126.56 вместо localhost?

## Причина

**Open Server** использует нестандартный IP адрес `127.127.126.56` для PostgreSQL по следующим причинам:

### 1. Изоляция от системных сервисов
- Open Server изолирует свои сервисы от системных установок PostgreSQL
- Это предотвращает конфликты портов и конфликты версий
- Позволяет иметь несколько версий PostgreSQL одновременно

### 2. Безопасность
- Изоляция снижает риск случайного подключения к неправильной базе данных
- Упрощает управление несколькими проектами

### 3. Техническая реализация Open Server
- Open Server создает виртуальную сетевую среду
- Использует специальный IP диапазон для своих сервисов
- Это стандартное поведение Open Server, а не ошибка

## Что такое 127.127.126.56?

Это **локальный IP адрес** (loopback), который:
- Работает только на вашем компьютере
- Не доступен извне (безопасно)
- Аналогичен `localhost` или `127.0.0.1`, но использует другой адрес

## Можно ли использовать localhost?

### Вариант 1: Использовать 127.127.126.56 (рекомендуется)
**Плюсы:**
- ✅ Работает "из коробки"
- ✅ Не требует изменений конфигурации
- ✅ Безопасно и изолировано

**Минусы:**
- ❌ Нестандартный адрес (может смущать)

### Вариант 2: Настроить PostgreSQL слушать на localhost
**Плюсы:**
- ✅ Стандартный адрес
- ✅ Более привычно

**Минусы:**
- ❌ Требует изменения конфигурации PostgreSQL
- ❌ Может вызвать конфликты с другими установками
- ❌ Нужно редактировать `postgresql.conf` и `pg_hba.conf`

## Как настроить localhost (если нужно)

Если вы хотите использовать `localhost`, нужно:

1. Найти файл `postgresql.conf` в папке установки PostgreSQL Open Server
   - Обычно: `C:\OpenServer\modules\database\PostgreSQL-XX\data\postgresql.conf`

2. Найти параметр `listen_addresses` и изменить:
   ```conf
   # Было:
   listen_addresses = '127.127.126.56'
   
   # Станет:
   listen_addresses = '*'  # или '127.0.0.1,127.127.126.56'
   ```

3. Найти файл `pg_hba.conf` и добавить:
   ```conf
   host    all    all    127.0.0.1/32    md5
   host    all    all    ::1/128         md5
   ```

4. Перезапустить PostgreSQL в Open Server

## Рекомендация

**Рекомендуется использовать `127.127.126.56`**, так как:
- Это стандартное поведение Open Server
- Не требует дополнительной настройки
- Работает надежно и безопасно
- Не вызывает конфликтов

В коде и конфигурациях можно использовать переменную окружения `DB_HOST`, что позволит легко переключаться между окружениями (локальная разработка vs продакшн).

## Текущая конфигурация

В проекте используется:
- **Локально (Open Server):** `DB_HOST=127.127.126.56`
- **Продакшн (сервер):** `DB_HOST=localhost`

Это позволяет использовать один и тот же код в разных окружениях без изменений.
